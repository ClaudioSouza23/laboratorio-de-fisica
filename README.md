# Laboratório de Eletrodinâmica

Simulações 3D interativas sobre potência elétrica, para usar em sala e em casa.

- **Secador de cabelo: quente ou morno?** (`secador.html`): por que a posição quente tem a menor resistência quando a tensão da tomada é fixa (P = U²/R). Inclui a questão UFAL 2010 com a análise das alternativas.
- **Duas lâmpadas: qual brilha mais?** (`lampadas.html`): as mesmas lâmpadas em paralelo (mesma tensão, P inversamente proporcional a R) e em série (mesma corrente, P diretamente proporcional a R).

Abra o `index.html` para escolher o experimento. As páginas precisam de internet para carregar a biblioteca 3D (three.js).
